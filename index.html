查核說明

這份清單來自一篇日文 X 貼文（2026-11-17 發表，約 2.9 萬次查看），原文連結全被截斷。本頁的 20 個網址已於 2026-11-17 逐一查證：18 項直接開頁或搜尋比對確認存在，另有兩項例外如下。

  • 17 Openverse API：查核時未能直接連線確認，存活是依據多個獨立來源在 2026 年 10 月前後的實測（匿名請求回傳 HTTP 200）佐證。
  • 16 Lottie：貼文連結截斷在「lottie-」之後，無法確定原貼文指的是哪個播放器。本頁依「網頁輕量向量動畫播放」的用途選 lottie-web；若指的是行動端，應為 lottie-android 或 lottie-ios。
  • 貼文宣稱「20 個都在 Muse 上動作確認過」，那只是貼文的說法。本頁只驗證連結存在、倉庫公開可存取、公開資訊描述相符，未實際安裝或執行任何一項。
  • 03 與 14 Remotion 為 source-available 授權：個人與三人以下團隊免費，四人以上公司須購買公司授權，使用前先讀授權頁。
  • 07 Blender 與 20 FFmpeg 的 GitHub 倉庫是官方鏡像，主要開發不在 GitHub 上進行。
  • 本頁每個工具的圖案是依它的用途繪製的示意動畫，幫助辨認與溝通，不是官方截圖，也不是工具實際跑出來的畫面。

2026-11-18 新增第 21 至 25 項，來自 Mikhailovichi（@MitCheese14）2026-11-15 的 X 貼文，主題是用 Muse 做副業。這五項與動態設計無關，依 nick 的決定以新分類「副業」加入本頁；連結已於 2026-11-18 直接開啟各 GitHub 倉庫確認存在。第 24 項依貼文寫法一張卡片掛兩個連結（yt-dlp 與 Whisper），不拆成兩項。

2026-11-18 再新增第 26 至 90 項，來自硅基練習生 JAXX（@jaxxchen003）2026-11-14 的 X 貼文所介紹的設計技能合集站（2026-11-18 快照，當日站上共 70 條）。合集裡已有相同倉庫的 3 條、合集內部重複的 1 條，以及與本頁第 1 項同倉庫的 motion-design 1 條都已扣掉，只加新的 65 條，並分成「網頁設計」「生圖」「生視頻」三個新分類。每張卡片的說明都以本站自己的話重寫，沒有照抄合集站文字；儲存順序也與合集站不同，加上每次開啟的隨機排序，順序不會跟原文一樣。合集站每天半夜更新，本頁是 2026-11-18 的快照，不會自動同步之後新增的條目。第 26 至 90 項的授權未逐一查核，使用前請以各倉庫的 LICENSE 檔案為準。

2026-11-18 再新增第 91 至 102 項，來自 Asteri（@Asteri_eth）2026-10-16 的 X 貼文「20 個開源倉庫撐起一間動態設計工作室」，並對照 AgentGid 2026-11-01 更新的核對文章〈A Motion Design Studio for Claude Code: 20 Open-Source Repos〉。該清單與本頁原有項目比對後，已有的 8 項（Remotion、Remotion Skills、Motion、GSAP、Three.js、react-three-rapier、react-postprocessing、FFmpeg）不重複收錄，只補先前缺的 12 項；連結、授權、星數與最近活動已於 2026-11-18 直接開啟各 GitHub 倉庫並以 GitHub API 實查。其中 91 Motion Canvas 與 101 Howler.js 久未發新版，功能完整可用，但出問題要自己修；96 dotLottie Web 與第 16 項 lottie-web 是不同播放器，兩者並列；94 GSAP Skills 此次獨立成卡，先前只在第 13 項 GSAP 的安裝指令裡出現。

分類沿用貼文截圖的分類列（Skills、3D、FX、Motion、Sound、Export），另加「副業」一類收第 21 至 25 項；12 Tweakpane 本質是參數調整工具，依貼文暫歸 FX。
